# Pathplore Training Consult

Official website for Pathplore Training Consult, an applied digital skills training institute.

🔗 Live site: pathploretrainingconsult.com 📦 Repo: github.com/Embiem-Agriccode/pathplore

# About

Pathplore Training Consult trains people in high-growth technical skills through project-based learning, taught by practicing industry engineers. This repository holds the institute's public website, where prospective students can learn about the programs, check admission details, explore internships, and get in touch.

# Programs

The site presents Pathplore's training tracks, including Data Science and Cyber Security, with admissions and internship information alongside.

# Pages
Page	Purpose
index.html	Home / landing page
about.html	Institutional profile and who Pathplore is
admissions.html	Admission information and enrollment
internships.html	Internship opportunities
contact.html	Contact details and enquiries

Other features: an Enroll Now call-to-action in the header and a floating WhatsApp contact button on every page.

# Tech Stack
HTML5: page structure (about 79% of the codebase)
CSS3: custom styling and responsive layout
JavaScript: lightweight interactivity in app.js
Hosting: Vercel, with a custom domain, deployed from the main branch

No build step and no framework, so the site is a plain static project.
Run Locally
